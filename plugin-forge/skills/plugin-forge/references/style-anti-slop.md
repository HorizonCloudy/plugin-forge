# style-anti-slop —— 双风格门禁规则库

来源与许可（全部 MIT，已审计，见仓库 AUDIT.md）：
- asd-ste100 2.0.5 kit（woosal1337/blog，videos/ep01-the-cure-for-ai-slop）——Layer 1/2 词与序
- humanizer v4.0.0（blader/humanizer）——英文 AI 痕迹模式库（A–F 类 26 条）
- Humanizer-zh（op7418/Humanizer-zh）——中文补充模式（F 类 6 条）
- ASD-STE100 Issue 9 为原文规范，版权属 ASD，本文只收录改写规则本身。

## Layer 1 —— 词（英文要点）

- 一物一名：check/verify/validate/confirm 不许轮换，选一个用到底（1.11, 9.4）。
- 短常用词：start、use、help、make sure、do、give、before、after、about、get、show、also。
- 主动句；施动者未知或无关时才用被动（3.6）。"the field is required" 这类过去分词作表语不算被动。
- 只用简单时态（3.2）：无现在完成时；不堆助动词（3.4）。
- 一句一个指令（5.2）；指令句 ≤20 词，描述句 ≤25 词。
- 不省冠词凑短（4.2）；名词前该有 a/an/the/this 就有（4.5，泛指与抽象概念除外）。
- 多词名词 ≤3 词（2.1），超了拆开或加连字符。
- 平实连接词：then、but、thus、as a result（4.4）。
- 禁营销形容词：seamless、robust、powerful、cutting-edge、effortless、world-class、revolutionary。
- 禁短语动词：spin up、dive into、kick off、roll out（9.3）。美式拼写（1.14）。

## Layer 2 —— 序（对"人"的交付）

下一动作第一行；编号步骤；真实估时（分钟/小时/天，不许"一些工作/一会儿"）；
无开场白无收尾；多轮工作标 step N of M；动作清单 ≤5，超了拆"现在做/之后做"。
参考文档、需要语气的写作不适用本层。

## 中文·词（与英文同等执行）

1. 一动作一名：检查/核实/确认/验证 选定一个用到底。
2. 平实词：用（非"采用/借助"）、之前（非"此前"）、帮助（非"赋能/助力"）、如果（非"若/倘若"）。
3. 删翻译腔公文腔："进行…操作"→直接用动词；"做出改进"→"改进"；"对 X 进行了优化"→"优化了 X"；"值得一提的是"→删。
4. 禁黑话堆砌：强大、无缝、极致、卓越、一站式、颠覆性、赋能、抓手、闭环、颗粒度、底层逻辑。
5. 主动句优先，写明施动者；别人做的事不用"被"。
6. 一句一件事；程序句 ≤40 字；条件在前逗号断开："如果测试失败，读取日志。"
7. 不堆助动词："可能需要进一步进行优化"→"需要优化"。

## humanizer 模式库（英文 26 条，按类速查）

- A 铺垫代替陈述：not-X-but-Y 反转、单句收尾戏剧腔、伪深刻格言、起跑式铺垫、与假想敌辩论。
- B 公式化节奏：强凑三段式、句首复读、破折号万能连接、限定词堆叠、连字符成对词、被动缺主语。
- C 拔高与借权威：AI 高频词（delve、leverage、tapestry、testament…）、意义拔高、模糊关联、
  -ing 尾缀补刀、宣传语、借权威、回避 is/are/has。
- D 公式化排版：粗体当装饰、装饰性标题、弯引号。
- E 聊天残留：客服腔、知识边界免责与猜测填充、首句复读标题、谈论文档本身。
- F 读者错位：向已知读者重复解释他懂的东西。

## Humanizer-zh 中文补充（6 条）

层叠的"的"、"进行＋动词"、被字句堆叠、四字词排比、"随着……的发展"式开头、套话收尾。

## 冲突裁决

1. 用户明确要求 > 本门禁。
2. 事实、数字、条件、范围限定词不为风格牺牲（两边技能的共同守卫）。
3. humanizer 保"作者声音"，ste100 剥"机器腔"：先剥机器腔；文本本就需要个人语气（博客、营销）时，
   ste100 Layer 1/2 不适用（见其 scope 表），humanizer 只删 AI 痕迹不改成公文腔。
4. hedge 与 qualifier 分开处理：删无信息量的"或许/可以说"；保留有信息量的限定（"仅 macOS"、"n=6"）。

## 核验工具

- 英文：`python scripts/ste-lint.py [--strict] [--shape] <文件>`（分数报告，flavored ≤2.5/100w，strict ≤1.5/100w）。
- 中文：按上面清单逐条自查；`check_structure.py` 思路（保护代码块/链接/标题/表格/编号步骤不被改写）可复用。
- 不为每条聊天回复起进程；长文交付前必跑。
